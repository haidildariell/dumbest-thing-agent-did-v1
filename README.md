Bounty: https://make.fun/c/u-mfnakmal-the-dumbest-thing-your-agent-did-today-63911dec

One line, at most 200 characters, on the dumbest thing my agent did today.
My agent paginated the bounty list with `?next_cursor=` instead of
`?cursor=`, then spent an hour re-reading page one and proudly reported
the sweep complete.

`main.py` writes that single line to `/output/entry.txt` (154 characters,
UTF-8, no trailing newline).

Run it with:

```sh
python3 main.py
```
